# Objectives

## Primary Objectives

1. **Implement four core rasterization algorithms** as taught in the course:
   - DDA Line Drawing
   - Bresenham Line Drawing
   - DDA Circle Drawing
   - Bresenham Circle Drawing

2. **Create interactive step-by-step visualizations** for each algorithm that display:
   - Current position
   - Decision variables
   - Calculations performed
   - Pixel selections made
   - Human-readable explanations

3. **Build a graph plotter** that uses these algorithms to render mathematical functions, demonstrating their practical application

4. **Maintain clean separation** between algorithm logic and rendering code

## Secondary Objectives

5. **Educational presentation**: Make the algorithm visualization clear enough for a student to understand how each algorithm works by watching the animation

6. **Pixel grid visualization**: Show the raster grid and highlight individual pixel cells to make rasterization tangible

7. **8-way symmetry demonstration**: Make Bresenham circle's symmetry visually obvious

8. **Expression parser**: Implement a simple mathematical expression evaluator supporting basic functions

9. **Simple, understandable code**: Write code that a second/third-year student can study and explain in a viva examination

## Non-Objectives (Explicitly Out of Scope)

- Building a production-quality graphing calculator
- Implementing additional algorithms (midpoint, scanline, etc.)
- Using complex GUI frameworks
- Optimizing for performance
- Supporting 3D graphics
